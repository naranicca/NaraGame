# NaraGame 에디터 튜토리얼

| 튜토리얼 | 장르 | 핵심 내용 |
|---|---|---|
| [클래식 플랫포머](platformer/README.md) | 2D 플랫포머 | 타일맵, 물리, 애니메이션, 적, HUD |
| [Sky Hopper](sky-hopper/README.md) | 원버튼 횡스크롤 비행 | 중력, 장애물 풀, 점수, 난이도, 재시작 |
| [Nightfall Arena](nightfall-arena/README.md) | 자동 공격 아레나 생존 | 적·투사체 풀, 자동 조준, 경험치, 레벨업 |
| [Ashen Vale](ashen-vale/README.md) | 아이소메트릭 액션 RPG | 타이틀, 마을 퀘스트, 절차 생성 던전, 전투, 인벤토리, 스킬 트리, 저장 |
| [Turbo Trails](turbo-trails/README.md) | 의사 3D 카트 레이싱 | 사다리꼴 트랙, 곡선·언덕, 드리프트, AI, 랩, 게임패드 |

모든 튜토리얼의 프로젝트명과 에셋명은 예제용 창작 명칭입니다.
각 폴더의 `Assets`에는 튜토리얼에서 사용하는 독창적인 이미지와 합성
사운드가 포함되어 있습니다. 새 프로젝트의 `Assets`로 복사하면 문서의
파일명을 그대로 사용할 수 있습니다. `Source/atlas.png`는 생성 원본이며
`samples/GenerateSampleAssets.ps1`로 개별 PNG와 WAV를 다시 만들 수 있습니다.
